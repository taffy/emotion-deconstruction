# emotion-deconstruction — 情绪解构 Skill

> 把一段「现实场景 + 情绪变化」的口述，转化为一份五学派联合解剖报告。
> 核心承诺：**五个维度用各自学派自己的理论骨架和术语推演**，不是把同一套大白话套五个标题。

一个 **WorkBuddy / 兼容 `SKILL.md` 的 Agent Skill**，纯 Markdown，无代码、无依赖、不联网。
1 个入口 + 3 个资源文件，整包 72 KB。

---

## 这是什么

你描述一件具体发生的事，以及情绪是怎么一步步变坏的 —— 它会输出一份五维度解剖报告，
让你看清：**这个反应不是性格缺陷，而是一套有来由、有硬件、有扳机的机制**。

五个维度，**顺序固定不可调换**：

| # | 学派 | 它回答的问题 | 关键术语 |
|---|---|---|---|
| 一 | **弗洛伊德**（经典精神分析） | 这个反应在重复谁、重复哪段旧关系 | 移情、退行、防御机制、本我-自我-超我、重复强迫 |
| 二 | **荣格**（分析心理学） | 你身上哪一块被夺权了 | 情结、人格面具、阴影、原型、对立转化、自性化 |
| 三 | **阿德勒**（个体心理学） | 你制造这个情绪，是为了什么目的 | 目的论、课题分离、自卑感、纵向 vs 横向关系、社会兴趣 |
| 四 | **认知神经科学** | 那几十秒里大脑具体发生了什么 | 预测误差/RPE、dACC 社交疼痛、杏仁核-HPA 轴、dlPFC 掉电、DMN |
| 五 | **进化心理学** | 这套程序原本是用来解决什么问题的 | 进化错配、社会计量器、地位防御、HADD、错误管理理论 |

每个维度末尾附**该派自己的对策**——必须是从该学派方法论派生出来的，不是通用鸡汤。
最后输出综合汇总（五层嵌套关系、主因果链、学派冲突的正面裁决、主次判断、分层行动方案）。

---

## 为什么是这五个、为什么这个顺序

五个维度**不在同一平面竞争**，而是五个层级嵌套：

```
功能由来（进化心理学）
   ↓
硬件机制（认知神经科学）
   ↓
个人内容（弗洛伊德）
   ↓
人格结构缺口（荣格）
   ↓
当下责任（阿德勒）
```

越往上越底层、越不可选；越往下越贴近你此刻能做的选择。这个顺序决定了报告的读法：
先看机制从哪来，再看你今天能改什么。

```
emotion-deconstruction/
├── SKILL.md                          # 入口：用途、六要素、执行流程、硬性质量要求、输出结构
├── README.md                         # 本文件

│   └── output-template.md            # 输出骨架模板（138 行）
```

| 文件 | 作用 | 什么时候读 |
|---|---|---|
| `references/theory-frameworks.md` | 各学派的术语清单，防止"术语串味" | 动笔每个维度**前**先读对应章节 |

> Agent 会按需加载其中的内容；`examples/` 是给人看的示范材料，不参与运行时加载。
> 范例若放进 `references/` 会被反复加载并与模板抢校准权重，导致输出照抄范例。

## 用法

直接用自然语言描述场景即可：

- 「解构一下：我今天在会上被领导当众否了，越想越气，回家还在反刍」
- 「我为什么会这样？每次被忽略就特别难受」
- 「五维度分析一下我这次的情绪」
- 「帮我分析内耗」

**不会触发**：纯信息查询（「弗洛伊德是谁」）、需要临床诊断的重度心理问题。

### 输入六要素（你可以不全给）

用户通常口述零散，Skill 会按六项整理成时间线。**缺失项不必强行追问**——
用合理假设补齐并标注；只有缺失会实质改变结论时才追问：

1. **事实层** —— 发生了什么（客观事实，不是你的解读）
2. **情绪层** —— 情绪如何一步步演变（诧异 → 委屈 → 越想越气 → 自我怀疑）
3. **念头层** —— 当时脑中冒出的具体句子（**原话价值最高**，直接决定前两层能挖多深）
4. **身体层** —— 心跳加速、胸口堵、胃发紧、手抖、失眠、反复刷手机
5. **时间层** —— 持续多久、最后靠什么结束的
6. **背景层** —— 与对方的关系和权力位置；**类似的感觉此前是否在别的关系里反复出现过**
   （这一项决定弗洛伊德与荣格层能否落地）

## 硬性质量要求

这些是 Skill 内置的自我约束，也是它区别于"让 AI 随便分析一下情绪"的地方：

- **术语自洽性自检** —— 遮住维度标题，读者应能凭内容分辨出这是哪一派。做不到就是失败。
- **每个维度两层结构** —— `机制是什么` → `在你身上怎么跑的`。只讲理论不落地 = 不合格。
- **敢下判断** —— 明确结论 + 优先级排序，禁止「可能……也可能……」式骑墙收尾。
- **冲突必须正面裁决** —— 弗洛伊德（被动受害者）与阿德勒（主动选择者）的内在矛盾
  不能并列堆砌，必须给出「谁在哪个时间尺度上成立」的裁决。
- **不道德化** —— 不说教、不指责。定位是「看清机制」，不是「改正错误」。
- **开场一句定调** —— 第一句话就给出全篇判断基调。
- **先纠正第一张多米诺骨牌** —— 找出场景中被误读的那个中性信号
  （「面无表情」被读成「敌意」，其实可能是「专注」）。这是全篇最有实用价值的一击。
- **长度不设上限** —— 充分展开，不为简洁牺牲深度。

## ⚠️ 上传 GitHub 前必须先改的一处

`SKILL.md` 第 41 行有一条**硬编码的个人归档路径**：

```markdown
用户要求归档时，写入 `C:\个人\AI问答记录\<场景关键词>.md`。
```

这是本机专用路径，**别人装了会写到不存在的目录**。上传前建议改成通用写法，例如：

```markdown
用户要求归档时，写入当前工作区下的 `情绪解构/<场景关键词>.md`；
若用户在指令中指定了目录，以用户指定为准。
```

或者保留原路径但改为"默认写入用户指定的归档目录，未指定时用当前工作区"。

> 我在 README 里保留了这个提醒，但**没有替你改 `SKILL.md`**——因为改了会影响你本机
> 现在的使用习惯（你一直在用 `C:\个人\AI问答记录\`）。要不要改，你决定。

## 边界

| 场景 | 处理 |
|---|---|
| 纯信息查询（「弗洛伊德是谁」「什么是课题分离」） | **不触发**，直接回答 |
| 需要临床诊断的重度心理问题 | **不诊断**，建议寻求专业帮助 |
| 用户只是想被安慰 | 本 Skill 的定位是「看清机制」不是「改正错误」，可能不合用 |

补充说明：五学派都是心理学理论框架，输出的是**解释与启发**，不是临床诊断结论。
重度抑郁、双相、创伤后应激等情况，请以精神科医师 / 临床心理学家的判断为准。

> ⚠️ 两个容易被漏掉的：
> 1. **`assets/output-template.md`** —— 它在 `assets/` 而不是 `references/`，
>    且 SKILL.md 明确要求「严格按 `assets/output-template.md` 的骨架展开」——
>    少了它，输出结构会散掉，五个维度的子章节会缺。
> 2. **`examples/worked-example.md`** —— 已经从 `references/` 挪出来了。如果漏传，
>    Agent 会按 SKILL.md 去 `examples/` 找却找不到，输出深度会明显下降。

### 不需要上传

- 无。这个 Skill 只有 4 个源文件 + README + LICENSE，没有流水线中间产物。

### 可选：让仓库更好懂

`examples/` 目录可以放更多真实分析案例，例如 `examples/演讲失控-五维度解构.md`。
**注意别放回 `references/`** —— 那是运行时依赖目录，放进去会和模板抢校准权重，
导致 Agent 把你的例子当成模板照抄。
