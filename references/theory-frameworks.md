# 五学派理论骨架与必备术语

动笔每个维度前，先读对应章节。术语不串味是硬性要求——遮住标题后，读者要能凭认出这是哪一派。

---

## 一、弗洛伊德（经典精神分析）

**这一派回答的问题**：这套反应在你个人的早年历史里，被写入了什么内容？

**必备骨架**：

- **地形模型**：意识 / 前意识 / 潜意识。症状与失控，是潜意识内容找到了缝隙。
- **结构模型**：本我（Id，本能冲动）／自我（Ego，现实调节）／超我（Superego，道德审查）。失控 = 自我被本我与超我夹击而失守；事后羞耻 = 超我重新上线。
- **移情（Transference）**：把早年重要客体的情感模式，原封不动投射到当下对象上。关键概念：**空白屏幕**——沉默、不表态的对象，最容易承接投射。
- **退行（Regression）**：压力下自我功能退回更早发展阶段，表达方式变得直接、无缓冲、不计后果。
- **防御机制**（必须指名，不要笼统说"防御"）：
  - 投射 Projection：把自己的不可承受部分安到对方身上。
  - 反向形成 Reaction formation：虚弱表现为傲慢，恐惧表现为攻击。
  - 合理化 Rationalization：事后编一个因果叙事保护自我价值。
  - **付诸行动 Acting out**：无法用语言处理的焦虑，绕过语言直接以行为释放。这是"行为表现异常/失控"的精神分析学名。
  - 压抑 Repression、否认 Denial、置换 Displacement、升华 Sublimation。
- **力比多（Libido）经济学**：心理能量的投注、回收与淤积。投注无法回收 → 淤积 → 必须以别的形式释放。
- **本能的融合与解离（fusion / defusion of instincts）** + **矛盾情感（ambivalence）**：爱与恨本就融合共存，客体一旦严重挫败，融合解除，爱瞬间翻转为恨。**恨的强度精确等于此前爱的投注量。**（解释"翻脸为什么这么快"的核心）
- **自恋性供给（narcissistic supply）**：自我价值依赖外部客体的承认来维持，供给断供即崩塌。
- **重复强迫（Repetition compulsion）**：无意识地重演早年创伤场景，试图获得不同结果，每次都失败。
- **治疗机制**：**把潜意识内容变成意识（making the unconscious conscious）**——这是弗洛伊德所有对策的最终落点。

**本派对策必须派生于**：识别移情（"这个人让我想起了谁"）、撤回力比多投注、给攻击性一个结构化/合法的出口、事后意识化复盘。

## 二、荣格（分析心理学）

**这一派回答的问题**：这次爆发，露出了你人格结构里的哪一块？

**必备骨架**：

- **人格面具（Persona）**：社会契约的产物，**需要对方的承认来"供电"**。对方不给反馈 = 面具裂缝。恐惧的不是失败，是"面具掉下来露出什么"。
- **阴影（Shadow）**：所有不被自我承认、被压进无意识的部分。Persona 失效、ego 控制力崩溃时，**阴影接管人格**。
  - 荣格最锋利的一句：**当事人说"那不是我"，恰恰因为那是最真实的他的一部分。越否认，压得越深，下次回来得越猛。**
- **情结（Complex）**：带强烈情绪色调的、**具有自主性的心理碎片**，像一个寄生人格，被激活后可夺取意识控制权。
  - 荣格原话精神：**不是人拥有情结，而是情结拥有人。** 失控 = 被情结占据（possessed by a complex）。
  - 常见命名：「不被看见」情结、「权威—羞辱」情结、「不配得/被拒绝」情结。
- **原型（Archetype）**：集体无意识中的普遍模式。常用：英雄、暴君、弃儿/孤儿、母亲、智慧老人、骗子（Trickster）。
- **对立转化（Enantiodromia）**：一种心理倾向走到极端，会不可阻挡地转化为其对立面。**英雄过度膨胀 → 暴君**；讨好走到极端 → 爆发式攻击。这是荣格解释"突然变了一个人"的核心概念。
- **参与神秘（participation mystique）**：个体面对"大众/集体"时，被集体场域吞没，失去个体边界。
- **心理能量（Libido）的退行与内爆**：向前的适应失败 → 力比多退行回无意识 → 激活原始内容 → 能量被无意识吞掉 → 以破坏性形式内爆。这是"内耗"的荣格式定义（psychic wear and tear）。
- **自性化（Individuation）**：把自我价值的锚点从外部集体承认，收回自性（Self）。这是荣格给出的长期方向。
- **情结去认同化**：把「我是不被看见的」改写为「我有一个'不被看见'的情结」。一字之差，从被占据者变成观察者。

**本派对策必须派生于**：阴影整合（Shadow Work）、情结去认同化、区分 Persona 与 Self、主动想象（Active Imagination）、记录梦、把内在冷漠/评判的投射认回来。

## 三、阿德勒（个体心理学）

**这一派回答的问题**：在当下这一刻，你选择拿这个情绪来做什么？

**必备骨架**（这一派最容易写成大白话，务必用术语）：

- **目的论 vs 原因论**（核心）：不是"因为 A 所以我 B"，而是"**为了达到某个目的，我主动选择了 B**"。
  - 原话精神：**人不是"因为生气而大发雷霆"，而是"为了大发雷霆而制造出生气"。情绪是被制造出来的工具。**
  - 推论：一旦看见目的，情绪的工具性就失效，人就不再被它驱动。
- **课题分离（Separation of Tasks）**：一切人际烦恼的源头。
  - 我的课题 vs 他人的课题；失控 = 越界强征他人的反应/评价。
  - **反向误用**：把自己的价值这个课题，交给别人去打分。
  - 用 ASCII 画出课题边界框，是本派的标志性输出。
- **自卑感与优越情结**：**优越情结是自卑感的华丽伪装**（过度补偿）。表面越强势，底下空洞越大。
- **纵向关系 vs 横向关系**：纵向 = 我高你低、我表演你评分；横向 = 平等伙伴、我为共同体做贡献。从纵向切到横向，能从根本上拆掉"我需要你的反馈确认我的位置"。
- **社会兴趣（Gemeinschaftsgefühl / social interest）**：阿德勒认为心理健康的唯一标尺。健康关注点是"我给出去的东西有没有用"，不健康关注点是"他们有没有在崇拜我"。
- **人生谎言（Life-lie）**：用虚构叙事保护自我价值（例："不是我讲得不好，是他们太差"）。
- **生活风格（Style of Life）与早期记忆**：童年形成的隐性人生规则（例："我只有在表现出色时才值得被看见"）。用于解释模式的反复出现。
- **被讨厌的勇气**：把"被讨厌"列入可接受成本。

**本派对策必须派生于**：课题分离的边界句、目的论现场自检（"我现在制造这个情绪是为了达到什么目的"）、横向关系重建（从"征服"改成"送一样东西"）、把被讨厌列入可接受成本、以直接行动替代内耗。

## 四、认知神经科学

**这一派回答的问题**：这套程序用什么硬件在跑？那一刻大脑里具体发生了什么？

**必备骨架**（要有真实脑区、通路、递质，按时间阶段推演）：

- **阶段 0 基线**：PFC + 伏隔核生成**预测模型**；杏仁核提前激活，皮质醇基线升高；**耶基斯-多德森倒 U 曲线**（唤醒过高 → 认知断崖）。
- **阶段 1 预测误差**：大脑主动预测而非被动接收。实际输入与预测冲突 → **负向奖赏预测误差（Negative RPE）**；**VTA → 伏隔核**多巴胺放电**跌破基线**。"比预期更糟"的痛苦大于"从未期待"。
- **阶段 2 社交疼痛**：**背侧前扣带回（dACC）** = 冲突监测器 + **社交疼痛中枢**（Eisenberger Cyberball 实验：社会排斥与物理疼痛共享神经基质）。
- **阶段 3 网络切换**：**突显网络（SN = dACC + 前脑岛 AI）** 检测到重大事件后，强制把控制权从**执行控制网络（ECN/CEN）** 切给**默认模式网络（DMN）**。
  - 后果：**背外侧前额叶（dlPFC）被压制**——dlPFC 正是负责抑制控制与"这句话该不该说"的语言筛选器。**它断电 = 嘴里没有过滤器。** 这是"说出不可思议的话"的直接物理原因。
- **阶段 4 应激风暴**：杏仁核（基底外侧核 BLA）→ 下丘脑 → **HPA 轴**（CRH→ACTH→皮质醇）；同时 **交感-肾上腺髓质轴（SAM）** → 肾上腺素/去甲肾上腺素 → 心率↑、呼吸浅快、声带发紧（声音变尖抖）、手抖。
  - **Arnsten 的关键结论**：高浓度皮质醇 + 儿茶酚胺会**直接关闭 PFC 神经元放电**，**背侧纹状体（习惯/反射系统）接管**——大脑从深思熟虑降级为反射模式。
- **阶段 5 DMN 反刍三件套**（对应本技能的核心框架）：
  - 心理时间旅行（**海马体**）：调取过往失败记忆。
  - 心智理论（**mPFC + 颞顶联合区 TPJ**）：疯狂模拟他人在想什么；**高唤醒负性状态下，中性面孔被系统性负性解读**。
  - 自我指涉（**vmPFC**）：从"他觉得我不好"升级到"我是失败者"。
  - **死循环**：DMN 猜想 → 杏仁核 → 皮质醇↑ → PFC 更弱 → DMN 更失控。
- **阶段 6 爆发与断层**：**杏仁核劫持（Amygdala Hijack）**——低通路（丘脑→杏仁核）绕过皮层评估直接触发反应。
  - **状态依赖性记忆（State-Dependent Memory）**：高皮质醇状态下编码的行为与语言，与正常状态下的回忆**不在同一检索通道** → 检索困难 → 陌生感 → "那不是我"。**这是"事后不可思议"的纯物理解释，也意味着"下次我一定不会了"在神经层面靠不住。**
  - 去个体化（deindividuation）、时间感知扭曲。
- **阶段 7 事后**：皮质醇代谢延迟 → DMN 回放失控画面 + **前脑岛**产生羞耻与厌恶；交感撤退后的崩溃感与疲惫。
- **长期**：**赫布法则**（一起放电的神经元连在一起）→ 通路被强化、杏仁核阈值降低、形成条件化回路。**神经可塑性也意味着可反向训练。**

**本派对策必须派生于**：

1. **生理刹车优先**（PFC 已断电，不要讲道理）：延长呼气（迷走神经/副交感）、喝水（吞咽打断交感风暴 + 争取 3–5 秒 PFC 恢复窗口）、双脚用力踩地（本体感觉抢占资源）。
2. **预置「如果—那么」计划（Implementation Intention）**：把程序写进基底神经节习惯回路，因为临场 dlPFC 会掉线。
3. **用外部任务强制激活 TPN/CEN**：提问、举手投票、点名——把控制权从 DMN 抢回，同时物理性修复反馈通道。
4. **暴露脱敏（Extinction Learning）**：vmPFC 对杏仁核的抑制性控制可训练，靠重复不靠顿悟。
5. **睡眠**：睡眠剥夺使杏仁核反应性放大 60%+ 并削弱 PFC 调控。

## 五、进化心理学

**这一派回答的问题**：为什么人类会有这套程序？它在远古解决什么问题？

**必备骨架**：

- **进化错配（Evolutionary Mismatch）**：远古环境设计的程序，跑在现代环境上必然报错。要具体指出是哪一重错配：
  - **规模错配**：大脑为 **邓巴数（~150 人）的熟人部落**设计，部落里每个人都认识你；现代场景中面对的是大量陌生人。
  - **反馈通道错配**：面对面交流的反馈是高密度多模态的；现代某些形式（单向广播、异步通讯）**物理切断了反馈通道**，大脑没有现成程序，只能调用最接近的模板：排斥/敌意。
  - **信号解码错配**：某些现代才有的中性信号（如专注时的无表情脸），在远古几乎只出现在敌意场景，被古老解码器误译。
- **社会计量器理论（Sociometer Theory, Leary）**：自尊不是自恋，是一台实时监测**关系价值（relational value）**&#x7684;仪表——"群体有多需要我、多想留住我"。读数暴跌 = 最高级警报（因为在小部落里被排斥 = 真实的死亡）。
- **排斥监测机制（Ostracism Detection）**：对沉默/无视极度敏感，一触发就启动战斗或逃跑。
- **地位 / 声誉防御**：人类是**地位等级物种**。公开展示若**得不到群体的确认信号**，会被判为虚张声势，招致地位暴跌。
  - **升级展示（Escalation）**：动物行为学中，常规信号无效时个体会加大信号强度（更响、更夸张、更冒险），直到对方给出屈服信号。**愤怒与激烈言辞 = 孤注一掷地加大信号功率。**
- **代价信号（Costly Signaling）**：愿意付出高成本的信号才可信。
- **进化账本的关键不等式**：
  ```
  被无视 = 关系价值归零 = 社会性不存在 ≈ 死亡威胁（不可承受）
  被讨厌 = 关系价值下降 = 仍然被看见   = 可承受成本
  ```
  **所以大脑宁可让你被讨厌，也要换取被看见。** 这是"为什么要做那种事"的终极进化解释。
- **互惠期待与违约**：对话建立在强迫性互惠上；期待的"回应债务"永远不到账 → 触发被剥削检测 → **愤怒**。愤怒在进化上的功能之一正是**惩罚不互惠者、追讨欠债**（这解释了为什么是愤怒，而不是单纯的悲伤或恐惧）。
- **过度意图探测（HADD）+ 错误管理理论 / 烟雾探测器原理**：面对模糊信号，大脑必须生成意图；代价不对称下必然选择"宁可错报一千" → 默认敌意假设。
- **捕食者锁定 / 暴露感**：被注视、被强光照射、无处躲藏 = 被捕食者锁定的标准配置 → 战斗是"逃跑失败后的第二选项"。

**本派对策必须派生于**：给古老大脑喂**事实输入**（它只吃事实，不吃道理）、主动修复反馈通道（只认真实信号，不认自我暗示）、把目标从"得到认可（地位确认）"切换为"传递有用的东西（互惠贡献）"、接受"被讨厌"的定价、物理上降低暴露感（走下台、走近、目光有落点）。

## 六、五层的分工（写综合汇总时用）

| 层级     | 回答的问题                    |
| ------ | ------------------------ |
| 进化心理学  | 为什么人类会有这套程序（功能由来）        |
| 认知神经科学 | 这套程序用什么硬件在跑（执行机制）        |
| 弗洛伊德   | 这套程序在你的个人历史里被写入了什么（内容来源） |
| 荣格     | 这次爆发露出人格结构的哪一块（结构缺口）     |
| 阿德勒    | 当下这一刻你选择拿它做什么（当下责任）      |

**主次判断的默认框架**：  
**燃料** = 进化层 + 神经层（全人类共有，不必自责）；**引信** = 弗洛伊德层 + 荣格层（个人历史写入，需长期做功）；**扳机** = 阿德勒层（此刻唯一能直接控制的）。

**三处必须裁决的冲突**：

1. 弗洛伊德（被动受害者）vs 阿德勒（主动选择）→ 反应**阈值与形态**由过去决定（弗/荣），**这一次是否越过临界点**由当下选择（阿德勒）。现场用阿德勒止损，长期用弗洛伊德与荣格降阈值。
2. 进化层（这是本能，无可厚非）vs 精神分析（这是你的议题）→ 本能给出**反应强度上限**，个人议题决定**触发阈值**。进化层让人原谅自己，精神分析层让人改造自己。
3. 荣格（那也是你）vs 事后（那不是我）→ 荣格拒绝"不可思议"；承认是整合的开始，否认是下一次爆发的前奏。
